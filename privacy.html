QON 개인정보 처리방침

시행일: 2026-11-11 · 적용 대상: 크롬 확장 "QON" 0.2.0 이상과 Windows 프로그램 "QON"(setup.exe, 예전 이름 "CSI 품질자동화")

1. 요약

  • 이 확장과 프로그램은 어떤 정보도 개발자나 다른 회사의 서버로 직접 보내지 않습니다. (사용자가 [의견 보내기]를 눌러 브라우저로 여는 구글 폼은 4장)
  • 다루는 정보는 CSI 품질시험 등록에 필요한 시험 값과 그 입력 기록뿐이며, 모두 사용자 PC 안에만 있습니다.
  • 정보를 팔거나, 광고에 쓰거나, 다른 목적으로 쓰지 않습니다.

2. 확장이 다루는 정보

정보어디서왜
CSI 자체품질시험·검사 등록 화면의 입력칸 — 시험항목 행 구성, 시험일자·시험기준·시험결과·단위·판정 칸, 재료명·시험장소·생산자(레미콘 업체)·비고 칸, 시험종목 검색 팝업의 목록·체크 칸CSI 웹사이트 gcloud.csi.go.kr의 등록 화면(sQltRptRegist.do)과 시험종목 검색 팝업(qStdrSrchTsAllPop.do)에서만입력하기 전에 행 구성과 빈칸을 확인하고, 사용자가 [시험종목 자동 선택]·[224 행 자동 준비]·[입력]을 누를 때만 종목을 고르거나 값을 채우기 위해
CSI 등록 화면의 등록 식별 칸(사업 관리번호·등록/수정 구분)위 등록 화면에서만확인한 뒤 입력하기 전까지 화면이 다른 등록으로 바뀌지 않았는지 비교하기 위해. 그 탭의 메모리에서 비교에만 쓰고 저장하거나 어디로도 보내지 않습니다
검토된 시험 값 — 시험일자, 콘크리트 규격, 슬럼프·공기량·염화물·온도·단위수량·압축강도 등 시험값, 원본 파일 이름, (현장이 둘 이상이면) 현장 이름같은 PC에서 도는 "QON" 프로그램의 웹 화면(http://csi.localhost:5173)사용자가 그 화면에서 검토를 마치고 [확장프로그램으로 보내기]를 눌렀을 때 CSI에 입력하기 위해(파일·현장 이름은 사이드 패널 표시용)
입력 직전 확인 정보 — 받은 값의 확인 결과, CSI 화면의 시험항목 행 위치·결과칸 개수, 탭·프레임 번호와 무작위 확인 값확장 → 같은 PC의 프로그램입력 직전에 "검토한 값과 지금 화면이 맞는지" 프로그램에 다시 확인하기 위해
버전 정보 — 확장·프로그램 버전 번호와 데이터 형식 번호확장 ↔ 같은 PC의 프로그램둘의 버전이 맞지 않을 때 입력을 막고 어느 쪽을 업데이트할지 알리기 위해
운영 상태 — 새 작업 허용 여부와 종류(운영 중·종료 등)같은 PC의 프로그램 → 확장시범 운영이 끝났을 때 새 자동 입력을 막기 위해
문제 보고 파일(사용자가 사이드 패널에서 [문제 보고 파일 만들기]를 누를 때만) — 확장 버전, 운영체제·크롬 버전, 연결 상태, 받은 자료 종류, 단계 상태·안내 글(값·파일 이름은 가림)사이드 패널 화면 → 사용자가 고른 PC 폴더의 파일사용자가 문의할 때 직접 첨부하기 위해. 확장이 어디로 보내지 않습니다

확장은 CSI 로그인 정보(아이디·비밀번호·쿠키)를 읽지 않으며, 위 두 CSI 주소 밖의 웹사이트 내용은 읽지 않습니다.
확장은 CSI의 저장·등록·제출 버튼을 누르지 않습니다.

3. 저장 위치와 보관 기간

확장은 다음을 브라우저 안의 확장 전용 저장소(이 PC·이 크롬 프로필의 localStorage와 IndexedDB)에만 둡니다.

저장하는 것내용보관
입력 기록실행 번호(무작위 값), 입력 종류, 상태(입력함·되돌림 등), 시각, 원본 PDF 파일 이름, 시험일자, 대상 문서를 구별하는 해시 값정리되지 않은 기록은 사용자가 사이드 패널에서 [기록 정리]를 누를 때까지, 정리된 기록은 최근 32건까지
위험 경고되돌리기가 확인되지 않았을 때 사용자에게 보인 경고 문구, 실행 번호, 탭 번호, 시각사용자가 확인하거나 되돌리기가 확인될 때까지
진행 안내[시험종목 자동 선택]의 진행 단계 글다음 실행 때 바뀜

시험값 자체, 로그인 정보, 연결용 토큰 원문은 저장하지 않습니다.
확장을 지우면(크롬 확장 관리 → 삭제) 이 저장소도 함께 지워집니다.

프로그램(setup.exe)은 분석 기록·로그·현장 설정을 사용자 PC의 %LOCALAPPDATA%\CSI-AutoRegister\에 둡니다. 프로그램을 지울 때 이 폴더를 지울지 묻습니다.

4. 외부 전송

  • 확장: 외부 서버로 보내는 요청이 없습니다. 확장이 연결하는 곳은 같은 PC의 프로그램 웹 화면(http://csi.localhost:5173, 사용자 PC 안의 루프백 주소)과, 사용자가 열어 둔 CSI 화면뿐입니다.
  • 프로그램의 운영 상태 확인(시범 운영): 프로그램(확장 아님)은 정해진 주소(제작자의 공개 저장소 qon-release의 GitHub 주소와, 같은 저장소를 연결한 qon-release.pages.dev)에서 서명된 운영 상태 파일(service.json — 운영 중·종료·공지·최소 버전)을 받기만 합니다(켤 때, 그 뒤에는 받기에 성공하면 약 30분·실패하면 약 5분마다). 이 요청에는 시험 값·사용자·현장 정보·설치 번호가 들어가지 않으며, 쿠키를 보내지 않고, 고정된 이름(QON-service-status)으로만 요청합니다. 파일을 받는 곳(GitHub 등)은 일반 웹 요청처럼 접속 IP 주소를 기록할 수 있습니다. 정해진 주소가 다른 HTTPS 주소로 넘기면(리다이렉트) 그 주소에서 받으며(http 주소로는 넘어가지 않음), 받은 파일은 프로그램에 든 공개키로 서명을 확인한 뒤에만 씁니다. 회사망에서는 이 요청이 프록시를 거칠 수 있습니다 — 프록시 환경 변수(HTTPS_PROXY 등)가 있으면 그것을, 없으면 Windows 프록시 설정을 쓰며, 환경 변수의 프록시 주소에 아이디·비밀번호가 들어 있으면 그 값이 그 프록시로 전달됩니다(운영 상태 파일을 주는 곳으로는 가지 않습니다). 설치 번호(처음 실행 때 만든 무작위 번호)는 내 PC에만 있고, 문제 보고 파일을 사용자가 직접 보낼 때 그 안에 들어가거나 아래 [의견 보내기] 폼에 미리 채워질 때만 PC 밖으로 나갑니다.
  • 프로그램의 [의견 보내기]: [의견 보내기]는 사용자의 브라우저로 구글 폼을 엽니다. QON은 직접 전송하지 않으며, 폼에 버전과 설치 번호(무작위 번호)만 미리 채웁니다. 제출은 사용자가 직접 할 때만 이루어집니다. [의견 보내기]를 누르면 폼 주소에 버전과 설치 번호(무작위 번호)가 담겨 구글로 전달됩니다. 제출하지 않아도 폼을 여는 순간 전달되며, 이후는 구글의 개인정보처리방침을 따릅니다.
  • 프로그램의 새 버전 확인: 설치 파일에 새 버전 정보 주소가 들어 있을 때만, 프로그램(확장 아님)은 켤 때, 그 뒤에는 마지막 확인에 성공했으면 하루(24시간)·실패했으면 1시간이 지나 웹 화면이 다시 물을 때 그 주소(공개 저장소의 latest.json 또는 회사 공유 폴더)에서 새 버전 정보 파일을 받기만 합니다(주소가 비어 있으면 확인하지 않습니다). 이 요청에는 사용자 데이터·현장 정보·시험 값·프로그램 버전이 들어가지 않으며, 쿠키를 보내지 않고, 고정된 이름(CSIQualityAuto-update-check)으로만 요청합니다. 파일을 받는 곳(GitHub 등)은 일반 웹 요청처럼 접속 IP 주소를 기록할 수 있습니다.
  • 새 버전 설치 파일은 사용자가 [받기]를 눌러 직접 받고 설치합니다. 자동으로 받거나 설치하지 않습니다.

5. 제3자 제공·판매

수집하는 정보가 외부로 나가지 않으므로 제3자에게 제공하거나 판매하지 않습니다. 광고·분석 도구를 넣지 않았습니다.

6. 사용자의 선택

  • 확장은 사용자가 버튼을 누를 때만 CSI 화면에 값을 씁니다.
  • 사이드 패널의 [기록 정리]는 정리되지 않은 입력 기록을 '정리됨'으로 바꿉니다(정리된 기록은 3장처럼 최근 32건까지 남습니다). 확장을 삭제하면 모든 입력 기록이 지워집니다.
  • 새 버전 확인을 원하지 않으면 프로그램 설치 폴더의 app\update.json에서 주소를 비우면 됩니다.

7. 변경

이 방침을 바꾸면 이 문서의 시행일을 고치고 같은 주소에 바뀐 내용을 올립니다.
